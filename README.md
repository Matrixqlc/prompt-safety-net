# Prompt Safety Net

一个 Tampermonkey 用户脚本，用于在 ChatGPT 网页中保护文字 Prompt：自动保存未发送草稿、归档已提交的 Prompt，并在网络离线或回复长期没有进展时提醒。

当前版本：**0.6.4**。本版增加有容量上限的本地诊断日志，不改变已有 Prompt 历史、收藏和导出格式。

## 安装与更新

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [`chatgpt_prompt_safety_net.user.js`](./chatgpt_prompt_safety_net.user.js)。
3. 点击 GitHub 页面里的 **Raw**；Tampermonkey 会识别 `.user.js` 并打开安装或更新界面。
4. 已安装的用户也可以在 Tampermonkey 中对该脚本检查更新；不用卸载或清空记录。
5. 更新后刷新已经打开的 ChatGPT 页面；展开右下角“Prompt 安全网”，诊断状态行应显示 **v0.6.4**。

## 自动更新

脚本已配置 `@updateURL` 和 `@downloadURL`，指向本仓库 `main` 分支的 Raw 文件。后续发布新版本时，提高 userscript 头部的 `@version` 后，Tampermonkey 可以检测并更新本地脚本；不保证在提交后立即自动检查。

> 自动更新依赖 Raw 文件可匿名访问，因此仓库需要保持为 Public。代码仓库不用于保存用户的 Prompt 或实际诊断日志。

## 功能

- 输入时自动保存当前会话的未发送草稿；刷新页面后可自动恢复。
- 在回车、点击发送按钮或表单提交时备份文字 Prompt。
- 历史 Prompt 自动去重：同样的 Prompt 再次使用时不会新增重复记录，而是更新最近使用时间并累计“已使用 N 次”。
- 支持恢复、复制、单条删除和收藏；收藏项优先显示，并在再次使用同一 Prompt 时保留收藏状态。
- “导出 Prompt”将当前全部 Prompt 历史导出为 JSON，保留正文、收藏状态、使用次数、首次/最近使用时间、状态和来源会话信息。
- 普通历史最多保留最近 200 条去重后的 Prompt；收藏项不参与这个上限，不会因历史滚动被自动淘汰。
- 按当前窗口高度和每条 Prompt 的实际渲染高度动态分页，不固定每页条数；Prompt 正文完整显示。
- 分页提供“上一页 / 下一页”、当前页和历史序号范围；窗口尺寸变化时重新分页。
- 对窄屏（≤ 640px）做布局适配。
- 浏览器离线时提示；发送后约两分钟没有可见回复进展时提示可能卡住。

## 诊断日志：有明确配额

展开安全网后，点击 **“导出诊断日志”**，下载 `prompt-safety-net-diagnostics-时间.json`。排查漏记时提供这份文件，而不是含正文的“导出 Prompt”。

| 项目 | 限制 |
| --- | --- |
| 日志条数 | 最多 500 条，淘汰最旧记录 |
| 日志总容量 | 最多 256 KiB（262,144 字节），按紧凑 UTF-8 JSON 计算，包含元数据；导出也受此限制 |
| 保留时间 | 7 天；启动、合并、导出及运行中的每分钟清理检查会淘汰过期记录 |
| 异常限频 | 同类存储/入口异常在单页面内 30 秒最多记录一次 |
| 事件总限频 | 每个页面每分钟最多接收 120 条事件，额外事件只累计限频计数 |
| 写入节流 | 普通日志约 2 秒合并写入；初始化、导出、页面隐藏或离开时尝试立即写入 |

这三项保留限制同时生效，不会“每天再分配 256 KiB”。同一脚本安装只使用一个诊断存储键，不按会话、标签页或日期新增日志存储键。内存待写日志也受条数和字节上限约束。关闭全部相关页面时脚本不运行，过期清理在下次运行时进行。

日志记录版本、启动、输入框识别状态、页面类型切换、发送来源、字符数、跳过原因、保存结果、响应出现、异常类型和网络在线状态。不逐次记录普通按键，不为不变的心跳状态重复产生日志；草稿成功日志最多每 30 秒一条。

**不记录 Prompt 正文、正文指纹、聊天回复、完整会话地址/ID、Cookie、令牌、附件或原始异常文本/调用栈。**使用封闭字段和值白名单；只记录错误类别和发生环节，不拦截网页网络请求，不收集整页控制台信息，不上传到服务器或 GitHub。

“清空诊断日志”只清空诊断数据，不删除 Prompt 历史、收藏或草稿。面板同时显示脚本版本、输入框识别情况、已观察到的 Prompt 存储异常和日志持久化状态。日志存储失败时保留有限的内存日志供导出，并明确提示，不递归写错误日志。

### 诊断边界

日志从更新后的运行开始记录，不能补回此前未记录的故障。日志有采样和淘汰，不是完整审计记录；多个标签页采用读取最新日志后合并写入，不提供跨标签页原子事务保证。同时写入可能覆盖部分事件，但不会突破单个日志槽的容量上限。页面崩溃或进程被强制结束时，最近尚未写入的事件可能丢失；日志存储完全不可用时，应在关闭页面前导出内存日志。

发送备份会进行存储 API 写入后的读回检查。保存失败或部分失败不再统一提示“已备份”；该检查不等于物理磁盘持久性保证。本版用于补齐可观测性，不声称已经确定或修复此前那次偶发漏记的根因。

## 数据与限制

- 数据仅保存在 Tampermonkey 的本地脚本存储中，不会上传到外部服务。
- 只备份文字 Prompt；附件和图片不会被保存。
- ChatGPT 页面结构可能变化；如输入框或发送按钮选择器失效，需要更新脚本适配。
- 不包含跨设备同步或打开旧对话时自动导入历史消息的功能。

## 测试

Node.js 18 或更高版本，无需安装 npm 依赖：

```sh
node --check chatgpt_prompt_safety_net.user.js
node --test tests/diagnostics.test.cjs
```

测试覆盖条数和字节双上限、7 天过期、限频、隐私过滤、存储异常、内存降级、发送去重、收藏保留及清理隔离。测试使用模拟的 GM 存储接口，不替代真实浏览器中的 Tampermonkey 验证。

## Prompt 导出格式

导出文件名形如 `prompt-safety-net-2026-09-21-003015.json`。

JSON 顶层包含 `format`、`schemaVersion`、`exportedAt`、`promptCount` 和 `prompts`。`format` 为 `prompt-safety-net`，`schemaVersion` 仍为 1。诊断导出使用独立的 `format: prompt-safety-net-diagnostics`，不会混入 Prompt 导出文件。
